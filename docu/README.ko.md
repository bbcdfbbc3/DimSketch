# DimSketch — 사진 실측 노트

[English README](../README.md) · [실행 명령](cli_usage.md) · [개발·검증](development.md)

여러 각도의 사진에 같은 물체·구멍·기준면과 실측값을 연결해 CAD 모델링 자료를 만드는 로컬 웹 앱이다. 치수는 직접 잰 값을 입력하며 사진 픽셀로 실제 길이를 계산하지 않는다. 자동 CAD 생성은 포함하지 않는다.

## 설치와 실행

Windows, Python 3.11 64비트와 데스크톱 브라우저가 필요하다. 저장소 루트의 PowerShell에서 실행한다.

```powershell
.\scripts\setup.ps1
.\scripts\start.ps1
```

- 설치는 저장소 안에 `.venv/`를 만들고 고정 버전의 패키지를 설치한다.
- 가상 환경을 별도로 활성화할 필요가 없다. 설치 후 앱 실행에는 인터넷이 필요하지 않다.
- 브라우저가 자동으로 열린다. 접속 주소는 `http://127.0.0.1:8765`다.
- 사용 중에는 PowerShell을 열어 두고, 종료하려면 `Ctrl+C`를 누른다.
- 스크립트 실행이 차단되면 현재 PowerShell에만 아래 설정을 적용한 뒤 다시 실행한다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\start.ps1
```

## 기록 순서

1. 프로젝트를 만들고 전체·정면·측면·사선 사진을 추가한다.
2. 사각형 또는 다각형 영역을 표시해 물체 A를 등록한다. 다른 사진에서는 기존 A를 연결한다.
3. 같은 구멍·점·면을 `A-H1`, `A-P1`, `A-F1` 같은 공통 기준으로 등록한다.
4. 측정 구간의 두 점을 찍고 직접 잰 값과 단위, 측정 기준을 입력한다. 사진에 보이지 않는 구간은 숫자와 설명만 기록할 수 있다.
5. 같은 치수는 기존 M 번호에 연결한다. 값이 다른 재측정은 이력을 보존하고 채택할 값을 직접 고른다.
6. 미측정·재확인 항목을 검토한 뒤 ZIP으로 내보낸다.

## 사진 조작

- 클립보드에 복사한 이미지나 캡처 화면은 프로젝트를 선택한 뒤 `Ctrl+V`로 사진 모음에 추가한다. macOS에서는 `Cmd+V`를 사용한다. 텍스트 입력창과 팝업에서는 사진 추가 대신 기존 붙여넣기 동작을 유지한다.
- 물체·치수 위에서도 **가운데 버튼(휠)을 누른 채 드래그**하면 사진을 이동한다. 모든 도구에서 선택과 작성 중인 도형을 유지한다.
- 휠은 확대·축소, `맞춤`은 사진 전체 보기다. 보기 변경은 실측값과 저장 좌표를 바꾸지 않는다.
- 선택 도구에서 표시·꼭짓점·라벨을 왼쪽 버튼으로 드래그해 수정한다. 빈 곳을 드래그하면 사진이 이동한다.
- 기존 물체를 다른 사진에 표시하려면 물체를 선택하고 `현재 사진에 영역 표시`를 누른다. `사각형` 또는 `다각형`을 고른 뒤 그리면 선택한 물체가 연결 대상으로 미리 선택된다.
- 선택한 물체의 `↻` 핸들로 영역을 회전한다. `Shift`는 15° 간격이다. 오른쪽에서 각도 입력이나 ±15° 버튼도 사용할 수 있다.
- 다각형은 꼭짓점을 클릭하고 `Enter` 또는 더블클릭으로 완료한다. `Esc`는 미확정 그리기·편집을 취소한다.
- `Ctrl+Z`는 실행 취소, `Ctrl+Y` 또는 `Ctrl+Shift+Z`는 다시 실행이다. `Delete`는 선택한 사진 표시만 삭제한다.

## 저장·백업·이전

- 드래그 종료 또는 `정보 저장`·`각도 적용`으로 확정한 마지막 변경에서 약 0.45초 후 자동 저장한다. 팝업의 `기록 완료`는 즉시 저장한다. 상단의 `모든 기록 저장됨`을 확인한다.
- `Ctrl+S`는 현재 입력 중인 폼을 확정하고 프로젝트를 즉시 저장한다. 팝업에서도 사용할 수 있으며, 입력 중인 폼이 없으면 상세 정보 폼과 저장 대기 중인 변경을 저장한다. macOS에서는 `Cmd+S`를 사용한다.
- 입력 폼에 작성 중인 내용은 완료 버튼 또는 저장 단축키로 확정한다. 잘못된 입력은 안내를 확인해 고친다. 저장 실패·다른 탭의 저장 충돌이 생기면 입력을 유지하고 안내한다.
- 기본 저장 폴더는 저장소 루트의 `.local/`다. 같은 저장 폴더는 서버 하나에서만 연다.
- ZIP에는 `project.json`, `originals/`, `images/`, `annotated/`, `docu/summary.md`가 들어간다. 원본 사진은 보존하며 표시 좌표는 EXIF 방향을 보정한 편집 사진 기준이다.
- 다른 PC나 이전 앱의 프로젝트는 ZIP 내보내기 → DimSketch의 `ZIP 불러오기`로 옮긴다. 불러오기는 별도 프로젝트를 만들어 기존 자료를 보존한다.
- `.local/`, `.venv/`, `.checks/`, ZIP은 Git에서 제외한다. 중요한 자료는 ZIP으로 따로 백업한다.

## 지원 범위

- 사진: 정지 JPG·PNG·WebP, 파일당 30 MiB·4천만 화소 이하, 프로젝트당 100장.
- HEIC·동영상·움직이는 이미지는 정지 JPG·PNG 등으로 변환해 등록한다.
- 요청과 가져올 ZIP은 512 MiB 이하, ZIP 해제 크기는 1 GiB 이하로 제한한다.
- 단위는 mm·cm, 측정 상태는 실측·대략·미측정이다. 미측정 값은 0으로 채우지 않는다.
- 높이차는 기준면과 위·아래 방향을 기록한다. 측정 오차는 제작 허용공차와 구분한다.
- 서버는 로컬 주소에만 접속하도록 구성한다. GitHub 소스 공개와 웹 서비스 배포는 별개다.
